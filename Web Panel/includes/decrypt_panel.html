解密教程

Windows 解密

使用 Jasmin Decryptor (WinForms GUI 程序)

1准备 RSA 私钥文件 jasmin_private.pem
2在目标主机运行 Jasmin Decryptor.exe
3点击图标选择 .pem 私钥文件
4程序自动扫描所有 .jasmin 文件并验证私钥
5验证通过后点击 Decrypt 按钮，等待进度条完成
6解密完成后自动清除勒索提示文件
SHA256 完整性校验确保每个文件100%还原
:: 或使用命令行 (需 .NET 6+)
cd "Jasmin Decryptor"
dotnet run -- jasmin_private.pem

Linux 解密

使用 jasmin_decrypt.py (Python3)

1上传私钥和解密脚本到目标主机
2安装依赖
pip3 install cryptography
3运行解密（自动扫描 /home /root /var /opt /tmp /srv）
python3 jasmin_decrypt.py jasmin_private.pem
4指定目录解密
python3 jasmin_decrypt.py jasmin_private.pem /home/user /var/www
5检查输出：每个文件显示 [+] 成功 或 [-] 失败
SHA256 校验确保完整还原，失败文件保持 .jasmin 不删除

macOS 解密

与 Linux 相同，使用 jasmin_decrypt.py

1安装 Python3 和依赖
brew install python3
pip3 install cryptography
2运行解密（自动扫描 ~/、/Users、/tmp）
python3 jasmin_decrypt.py jasmin_private.pem
3指定目录
python3 jasmin_decrypt.py jasmin_private.pem ~/Documents /Users/Shared
同样支持 SHA256 完整性校验
