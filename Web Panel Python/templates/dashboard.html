解密教程

Windows 解密

使用 Jasmin Decryptor (WinForms GUI)

1准备 RSA 私钥 jasmin_private.pem
2运行 Jasmin Decryptor.exe
3选择 .pem 私钥文件
4自动扫描验证 → 点击 Decrypt
SHA256 校验确保完整还原

Linux 解密

pip3 install cryptography
python3 jasmin_decrypt.py jasmin_private.pem
1上传私钥 + 脚本到目标
2运行解密，自动扫描 /home /root /var
3指定目录: python3 jasmin_decrypt.py key.pem /path

macOS 解密

pip3 install cryptography
python3 jasmin_decrypt.py jasmin_private.pem
1与 Linux 相同流程
2自动扫描 ~/、/Users、/tmp
